# WorktreeProof onboarding (Claude Code)

Use this as an optional local guide. Report unavailable host capabilities
instead of emulating them. Do not install software, call a network, read
credentials, or write over existing files.

Use the same `.worktree-proof/` state and schemas as Codex. Bridge messages are
explicit local files and never launch Codex or forward hidden context. Treat a
task mode as `unknown` unless the host explicitly reports it.
