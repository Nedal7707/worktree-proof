# Provenance

WorktreeProof 0.2.0 is newly authored source for this project. The package, documentation, schemas, examples, and Agent Skills were written for WorktreeProof and do not rely on copied material from unrelated repositories or service datasets.

This statement is about source provenance, not a claim that every idea is novel. The project builds on ordinary open-source practices such as JSON records, path normalization, semantic versioning, and the Apache License 2.0.

WorktreeProof is an unofficial community project and is not affiliated with, endorsed by, or sponsored by OpenAI. It makes no claim of official support, broad adoption, benchmark superiority, or production suitability for every environment.

Contributors should preserve this statement when adding generated material or third-party assets, and should add any required attribution to [NOTICE.md](../NOTICE.md).
